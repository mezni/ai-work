# Experiment 01 — Baseline LLM Application

## Objective

Create the simplest possible LLM application before introducing
agentic behavior.

## Input

A plain-text support question.

## Process

1. Create a user message.
2. Send the message to Claude.
3. Receive the response.
4. Print the response.

## Architecture

User
  ↓
Prompt
  ↓
Claude
  ↓
Response

## Agentic capabilities

None.

## Tools

None.

## Memory

None.

## Evaluation

None.

## Observations

This is a standard LLM application rather than an agent.
