# Broadband Connectivity

## Symptoms
- Intermittent internet connectivity
- Slow web page loading
- Frequent disconnections

## Common Causes
- Loose cable connections
- Modem or router malfunction
- ISP outage in the area
- DNS configuration issues

## Troubleshooting Steps
1. Check all physical connections are secure
2. Power cycle the modem/router
3. Verify ISP status in your area
4. Try alternative DNS servers (8.8.8.8, 1.1.1.1)
5. Check modem configuration pages

## Prevention
- Use quality cables and connectors
- Place router in central location
- Keep firmware updated
- Regularly restart network equipment
