# LTE Troubleshooting

## Symptoms
- No service or limited service on LTE network
- Frequent connection drops
- Slow data speeds

## Common Causes
- SIM card not provisioned for LTE
- Network registration issues
- APN configuration incorrect
- Hardware damage to device

## Troubleshooting Steps
1. Verify SIM card is inserted correctly
2. Check APN settings match carrier requirements
3. Restart the device to force network re-registration
4. Check for carrier settings update
5. Test in different locations to rule out coverage issues

## Prevention
- Keep device software up to date
- Ensure correct carrier configuration
- Avoid unofficial firmware modifications
